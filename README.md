# Glyphshift

[使用文档](docs/index.md)

简体中文 · [English](README.en.md)

Glyphshift 是一款面向 Windows 桌面软件与游戏的运行时界面翻译工具。它在软件运行时捕获界面原文，并按
字典替换为你选择的目标语言；字典可以使用任意源语言和目标语言，整个过程不修改目标软件的安装文件。

## Glyphshift 解决什么问题

很多专业工具、旧软件和独立应用没有完整本地化。传统修改资源文件的方案容易被更新覆盖，也很难处理
自绘菜单、面板和运行时生成的文字。Glyphshift 把这些问题拆成可验证、可复用的三部分：

- 用工作流确认目标界面实际绘制了哪些文字，以及哪种拦截方式能够覆盖它。
- 用独立字典保存原文与译文；同一份字典可以继续编辑、导入、导出和复用。
- 用工作流把软件、字典、拦截方式和可选字体策略组合起来，并持续维持运行期翻译。

它适合需要长期使用未本地化桌面软件的用户，也适合维护共享界面字典的译者和工具作者。

## 它如何工作

1. **新建工作流，设置软件**：选择运行中的程序、快捷捕获或浏览程序文件，也可以从最近记录里选。工作流会自动命名。
2. **用工作流验证并收集文字**：打开目标菜单、对话框或面板，确认可用的兼容方式。译文可以手工填写，
   也可以用 AI 补全空白项，并保存到所选字典。
3. **启用工作流**：选择软件、字典、兼容方式和可选字体设置。启用后，Glyphshift 会在目标运行时
   应用并维持这份翻译期望。

收集、翻译和运行都在同一个工作流中完成。每个工作流对应一个软件，其他软件可以复制后配置。

## 核心能力

- **运行时文字替换**：不修改目标安装目录，停止工作流即可撤销 Glyphshift 的运行期影响。
- **可恢复工作流**：收集界面原文、出现次数和技术来源，支持暂停、继续、筛选、停止运行和选择字典。
- **可复用字典**：每份字典独立声明源语言和目标语言，并维护版本、元数据和原文到译文的映射；语言
  组合不受 Glyphshift 自身界面语言限制。
- **工作流组合**：每个软件独立选择兼容方式、多个有序字典和可选字体设置。
- **后台 AI 补全**：支持 OpenAI、Anthropic、Gemini、OpenAI-compatible、Ollama 与本机 Codex 订阅；
  同时只运行一个任务，切换页面不停止，并记录批次、耗时和供应商实报 Token。
- **多种软件兼容方式**：覆盖多类 Windows 原生与框架界面；实际效果以工作流结果为准。
- **中英文应用界面**：Glyphshift 自身目前支持简体中文与 English，并提供深色、浅色和跟随系统主题；
  这不会限制字典可以翻译的语言。

字典与工作流支持 JSON、CSV 导入导出。导入字典时可选择追加、同词条覆盖或整体替换；CSV 校验通过后补充语言等信息。指定一本写入字典后，其他所选字典按原文排除重复，不论译文是否为空。

## 开始使用

1. 启动 Glyphshift 和要翻译的软件。两者需要处于相同权限级别；管理员目标通常也需要管理员模式的
   Glyphshift。
2. 新建工作流，先设置软件，再选择适用的兼容方式。
3. 选择所需字典。需要收集原文时，指定一本写入字典或创建新字典；其他所选字典已有的原文不会重复追加。
4. 启动工作流并打开“收集与翻译”，操作目标软件的菜单和面板，手工填写译文或使用 AI 补全。
5. 在目标界面确认翻译效果；停止后保留字典，可再次运行同一工作流。

保存译文后，可用工作流的刷新按钮请求更新目标文字。即时刷新取决于适配器与控件支持；部分界面仍需重新打开或推进对话。捕获到完整原文不代表当前画面已完成替换，应以目标界面为准。

如果没有捕获到文字，先让目标界面保持可见，再在工作流设置中尝试其他兼容方式。帮助页提供软件未
启动、权限不匹配和无文字捕获等恢复步骤。

## AI 翻译与隐私

每个 AI 配置保存服务地址、模型、思考模式、分批、同时请求数、超时、重试和本机跳过规则。翻译默认
关闭额外思考，避免普通界面文字产生不必要的等待和费用。API Key 随 AI 配置明文保存在本机文件中，
设置表单默认遮蔽并支持显示；请只在受信电脑上使用。

Codex 订阅使用这台电脑上已经登录的 Codex，翻译会占用订阅额度。任务运行期间只有目标字典保持只读，
其他功能可以继续使用；真正退出会中断任务，但不会自动重发请求。

只有当前计划选中的候选原文会发送给你选择的 AI 服务；已翻译内容以及命中过滤规则的数字、路径、URL、
快捷键等内容会在本机跳过。使用云端模型前，请确认所选 AI 服务的数据处理和计费政策。

## 适用范围与边界

- 当前发布面向 Windows 桌面软件与游戏。
- Glyphshift 依赖目标软件实际使用的绘制技术，不保证覆盖所有应用、所有窗口或所有文字。
- 它不是修改安装包的语言补丁，也不是对整个屏幕进行 OCR 后覆盖一层翻译。
- 进程发现、文字捕获和替换决策都不等于最终像素一定可见；请用工作流和目标界面进行实际确认。
- 目标软件升级后可能改变绘制路径，需要重新用工作流验证。

建议保留重要字典的导出副本，并在目标软件中确认捕获、替换、刷新和停止运行后的恢复效果。
