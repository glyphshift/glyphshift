# 常见问题

## 抓不到文字

先确认目标软件已经启动，工作流也在运行。打开需要翻译的菜单、窗口或对话，让文字实际出现。

还是没有内容，就调整适配器试试。文字如果已经变成图片或纹理，普通文字拦截方式可能抓不到。

## 有原文和译文，画面却没变

在“任务操作”里点“强制刷新文字”。没有变化时，重新打开对应窗口或推进游戏对话。

能抓到原文，不代表当前画面一定支持立即替换。

## 连接失败或开始运行没反应

先确认 Glyphshift 和目标软件的权限一致。目标用管理员权限运行时，Glyphshift 通常也要用管理员权限。

如果刚换过 Glyphshift 版本或适配器，目标进程里可能还留着旧组件。先保存目标软件里的工作，完全退出并重新打开，再启动工作流。

## AI 测试连接很慢

测试最多等 30 秒。本地模型第一次启动需要加载，加载好后可以再测一次。翻译任务有自己的超时设置，不等同于测试连接。

检查服务地址、模型名称和 API Key。模型名称要与服务里提供的名称一致。

## CSV 译文删了还能导入吗

可以，空译文会作为待翻译内容。

如果提示原文有不同译文，说明同一句原文出现了多次，且译文不一样。保留你想用的那一行再导入。具体格式见[字典](dictionaries.md)。

## 怎么关掉更新提示

在“设置 → 软件更新”里关闭“启动时检查更新”。以后不会自动检查，需要时可以手动点“检查更新”。

新版提示也可以直接点关闭。下载按钮会打开下载页面，不会自动安装。

## 停止后为什么还有组件

部分适配器停用后会停止替换文字，但组件要等目标软件退出才会释放。需要彻底清掉时，保存工作后重启目标软件。
