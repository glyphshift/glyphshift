# 快速开始

## 1. 新建工作流，设置软件

打开 Glyphshift，点“新建工作流”。第一步是“设置软件”：可以浏览程序文件、选择正在运行的软件，或用快捷键捕获目标窗口。最近用过的软件也会列在这里。

选好软件后，工作流名称会自动填写；想换个名字，在“基础配置”里改就行。清空最近记录不会影响已建好的工作流。

## 2. 选择兼容方式

一个工作流对应一个软件。选好目标，再选择兼容方式。不确定选哪个，可以先试与目标界面类型相近的方式。

要处理另一个软件，可以复制工作流后修改。

## 3. 添加字典

点“添加字典”，左侧默认是“创建新字典”，右侧是“已有字典”。源语言是原文的语言，目标语言是你想翻译成的语言。

把用来保存新内容的字典勾成“写入”。只选一本时，就用这一本。

## 4. 开始收集和翻译

点“开始运行”，进入“收集与翻译”。打开目标软件的菜单、窗口或游戏对话，让需要翻译的文字出现。

找到原文后，填写译文，或者用 [AI 补全](ai-translation.md)。在字典编辑页改了内容，要点“保存字典”。

## 5. 看看效果

回到目标软件确认译文。如果当前画面没变，可以在“任务操作”里点“强制刷新文字”。有的界面还需要重新打开，游戏可能要进入下一句对话。

不用时点“停止运行”，字典会保留。遇到问题先看[常见问题](faq.md)。
