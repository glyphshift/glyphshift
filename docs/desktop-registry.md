# 桌面在线字典

桌面的“字典 → 在线目录”已连接共享 Registry 客户端。配置后可搜索、按标签筛选、翻页、安装和更新。
无配置或服务不可用时显示明确错误，本地字典仍可使用。当前没有生产服务地址、公钥或账户预置。

## 受信配置

启动 App 前，将 `GLYPHSHIFT_REGISTRY_CONFIG` 设置为配置文件的绝对路径。配置由部署者管理，不接收网页提供的服务 URL、信任文件或下载地址。

```json
{
  "schema": "glyphshift.desktop-registry/1",
  "origin": "https://registry.example",
  "catalogId": "glyphshift.official",
  "trustFile": "release-trust.json"
}
```

`registry.example` 是保留示例域名。`trustFile` 指向经独立可信渠道获取的 `glyphshift.release-trust/1` 公钥配置，格式见 [Registry 客户端](registry-client.md)。
可选 `caFile` 指向私有 CA PEM；TLS 校验始终开启。文件路径可相对于配置文件目录，或使用绝对路径；文件、密钥和本机配置放在 `local-test/`。
`catalogId` 应固定绑定同一受信服务，不应跨服务复用。配置文件环境变量在启动时捕获，文件和公钥在操作时重新读取。
无效配置只影响在线操作，不阻止本地工作区启动。配置中不需要账户令牌、client secret 或签名私钥。

需要构建或启动供检查时继续使用 `scripts/review-app.ps1`，不单独构建 shell 搭配旧 Runtime。

## 操作与并发

- 搜索使用后台任务，网络请求不持有桌面工作区互斥锁。当前展示原件的名称/说明预览，不自动翻译元数据；语言筛选 API 已支持，GUI 当前提供文本和标签筛选。
- 安装请求固定所选目录 ID、字典 ID、版本和发布者；界面不提交任意 URL 或公钥。
- 后台获取 proof、下载、静态检查并再次读取 proof，得到不可序列化的短期准备结果。
- 提交时重新取得工作区编辑锁，复查 AI 编辑锁、退出状态、配置是否改变、最新受信公钥和文件修改情况。
- 准备结果超过 30 秒不能提交；这限制本地等待，不是远端可用状态的事务保证。需要重试时重新执行下载与检查。
- 字典落盘沿用现有安装存储及崩溃恢复，然后重载字典并协调已启用工作流。提交过程不执行网络请求。
- 新安装拒绝同 ID 已有内容；更新只替换未修改的已验证版本。GUI 不提供强制覆盖，服务端命令和共享客户端同样拒绝该策略。
- 安装失败时保留目录结果并显示错误，允许重试。保留本地修改时先导出备份，再由用户管理本地内容。

桌面 API 升为 37，安装请求新增必填 `publisherIdentity`。尚未接入账户登录、网页深链接、插件管理界面或生产配置分发。

## 验收边界

桌面 Rust 测试覆盖配置/身份及既有编辑行为，共享客户端覆盖提交前的编辑冲突、密钥撤销、准备结果过期与禁止强制覆盖。
真实 Go Registry + HTTPS 验收覆盖发现、详情、验签和安装；Playwright CLI 验证目录查询、发布者传递、冲突提示及错误后重试。
Playwright 使用 Tauri 命令测试替身；它与真实 HTTPS 验收是两组互补测试，不代表生产站点已部署，也没有启动真实桌面 Runtime。
