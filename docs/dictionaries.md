# 字典

字典就是原文和译文的对应表，可以独立保存和复用。译文可以先留空，之后再手动翻译或交给 AI。

## 编辑和保存

打开字典，搜索原文或译文后修改。改完点“保存字典”。

每页可以显示 50、100 或 200 条。表头勾选框会选中当前筛选结果，包括其他页。删除前留意选中了多少条。

清空字典时会弹窗确认，直接点击“确认清空”即可；清空后仍要保存才会写入文件。

## 导入和导出

在字典列表点“导入”，可以多选 JSON、CSV、SRT，也可以混选。选择分别创建多个字典，或合并成一个字典，然后确认名称和语言。分别创建时可以统一设置语言，也能单独修改。

已有字典内，在“字典操作”里选导入格式，可以一次选择同格式的多个文件，追加、覆盖或替换当前字典。导出支持 JSON、CSV；字典列表支持多选后批量导出。

- **JSON：** 带词条、语言和字典信息，适合备份、分享。
- **SRT：** 提取字幕正文，保留正文换行，去掉序号和时间轴，重复正文合并。译文留空，需要补充字典语言。不支持导出 SRT，因为字典不保存时间轴。
- **CSV：** 只有原文和译文，适合用表格软件编辑。导入为新字典时，要补充语言等设置。

CSV 使用 UTF-8 编码，保留两列：

```csv
source,translation
Open,打开
Save,
```

译文可以留空，原文不行。原文、译文都相同的重复行会合并；同一句原文出现不同译文时，会提示你先处理冲突。

多文件合并时，相同原文只保留一条。可以选择优先保留靠前或靠后文件的译文，空译文不会覆盖其他文件的已有译文。合并后的内容使用统一的语言设置，请检查所选文件是否适合放在一起。

所有文件会先检查，通过后才允许导入。有文件出错时，本轮不会创建任何字典。分别创建时如果保存中途失败，会显示已完成数量，在同一弹窗里重试只处理剩余文件；关闭弹窗后已创建的字典会保留。

导入出错时会显示文件名和具体原因：CSV 会指出文件里的行号，列数不对会说明应有几列、实际几列，译文冲突会指出涉及的两行。JSON 格式错误会显示行号和列号。SRT 会指出出错的序号、时间轴或正文所在行。先修好提示的问题，再重新导入。

播放器字幕可以先导入 SRT、补全译文，再启动工作流和播放器、打开字幕。字典导入不会自动刷新播放器已有的字幕缓存。

用表格软件编辑时，建议把原文列当作文本，避免数字、日期或前面的零被自动改掉。

## 三种导入方式

- **追加：** 只加字典里没有的原文，已有内容不动。
- **覆盖：** 原文相同就使用导入的译文，没有的原文也会加进来。空译文也会覆盖原译文。
- **替换：** 清空原来的全部条目，再放入导入内容。需要额外确认。

导入到已打开的字典后，先检查内容，再保存。

## 字体

字典设置里可以搜索本机字体，也可以设置字号比例。工作流选择“优先字典字体”时才会按这份设置使用；最终还要看兼容方式是否支持。

## 本机文件

在“设置 → 数据”里点“打开字典文件夹”，就能找到本机保存的字典。平时也可以导出 JSON 留一份备份。

## 隐藏不想看的内容

先在设置的“文字过滤”里调整跳过规则，再在字典里勾选“隐藏跳过的条目”。这些内容只是不显示，不会被删除；取消勾选就能看到。AI 补全也用同一套规则，不再跟着 AI 配置切换。

大字典首次开启、改原文或改规则时需要检查，翻页直接复用结果。
