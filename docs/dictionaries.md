# 字典

字典就是原文和译文的对应表，可以独立保存和复用。译文可以先留空，之后再手动翻译或交给 AI。

## 编辑和保存

打开字典，搜索原文或译文后修改。改完点“保存字典”。

可以按“已翻译”或“未翻译”筛选，方便检查进度。

工作流列表和本地字典库默认按最近使用排序，也可切换为最早使用、名称升序或名称降序，排序选择会自动保存。

每页可以显示 50、100 或 200 条。表头勾选框会选中当前筛选结果，包括其他页。删除前留意选中了多少条。

清空字典时会弹窗确认。保存后，全部词条及关联写入工作流的捕获内容一并清空；空字典也可以执行清空。

## 导入和导出

在字典列表点“导入”，可以多选 JSON、CSV、SRT，也可以混选。选择分别创建多个字典，或合并成一个字典，然后确认名称和语言。分别创建时可以统一设置语言，也能单独修改。

已有字典内，在“字典操作”里选导入格式，可以一次选择同格式的多个文件，追加、覆盖或替换当前字典。导出支持 JSON、CSV；字典列表支持多选后批量导出。

- **JSON：** 带词条、语言和字典信息，适合备份、分享。
- **SRT：** 提取字幕正文，保留正文换行，去掉序号和时间轴，重复正文合并。译文留空，需要补充字典语言。不支持导出 SRT，因为字典不保存时间轴。
- **CSV：** 只有原文和译文，适合用表格软件编辑。导入为新字典时，要补充语言等设置。

CSV 使用 UTF-8 编码，保留两列：

```csv
source,translation
Open,打开
Save,
```

译文可以留空，原文不行。原文、译文都相同的重复行会合并；同一句原文出现不同译文时，会提示你先处理冲突。

多文件合并时，相同原文只保留一条。可以选择优先保留靠前或靠后文件的译文，空译文不会覆盖其他文件的已有译文。合并后的内容使用统一的语言设置，请检查所选文件是否适合放在一起。

所有文件会先检查，通过后才允许导入。有文件出错时，本轮不会创建任何字典。分别创建时如果保存中途失败，会显示已完成数量，在同一弹窗里重试只处理剩余文件；关闭弹窗后已创建的字典会保留。

导入出错时会显示文件名和具体原因：CSV 会指出文件里的行号，列数不对会说明应有几列、实际几列，译文冲突会指出涉及的两行。JSON 格式错误会显示行号和列号。SRT 会指出出错的序号、时间轴或正文所在行。先修好提示的问题，再重新导入。

播放器字幕可以先导入 SRT、补全译文，再启动工作流和播放器、打开字幕。字典导入不会自动刷新播放器已有的字幕缓存。

用表格软件编辑时，建议把原文列当作文本，避免数字、日期或前面的零被自动改掉。

## 三种导入方式

- **追加：** 只加字典里没有的原文，已有内容不动。
- **覆盖：** 原文相同就使用导入的译文，没有的原文也会加进来。空译文也会覆盖原译文。
- **替换：** 清空原来的全部条目，再放入导入内容。需要额外确认。

导入到已打开的字典后，先检查内容，再保存。

## 字体

字体和字号在工作流里设置，不跟着字典文件走。可以设置工作流默认值，也可以给其中某本字典单独设置。同一本字典可以在不同工作流里用不同字体，最终效果取决于适配器是否支持。

## 本机文件

在“设置 → 数据”里点“打开字典文件夹”，就能找到本机保存的字典。平时也可以导出 JSON 留一份备份。

## 字典正则规则

在字典设置中编辑正则规则。规则是字典元数据，随 JSON 字典包导入、导出、发布和更新；CSV 只包含词条，不携带规则。全局“文字处理”只保留不再收录过滤，没有全局替换规则。

例如：

```text
匹配原文：^(.+?)(:[ \t]*[0-9]+)$
替换为：{{TR}}$2
```

`{{TR}}` 是第一组文字的字典译文。`$1`、`$2` 是第一对、第二对括号找到的内容，`$$` 表示美元符号。`Total:18` 分成 `Total` 和 `:18`；字典只需要 `Total → 总计`，显示时拼成 `总计:18`。

先按工作流的字典顺序、再按字典内部的规则顺序匹配，首条匹配生效。规则只查所属字典，优先于完整词条译文；没有需要的译文时保持完整原文，不回退到旧的整条译文。不匹配任何规则才执行原有完整词条查找。

新原文收录使用同样的拆分方式，数值波动不会产生多个词条。写入字典的规则提取出的固定文字可自动收录；附加字典的规则不会把新词条写进别的字典。自动翻译也使用固定文字。关闭规则后恢复完整原文收录与查找；已有词条保留，用户可搜索后自行删除。修改规则随字典修订更新运行配置和相关缓存，不迁移历史条目。

规则末尾可输入模拟原文和可选模拟译文，点击“测试”查看匹配内容、捕获组与替换结果。测试只运行这一条，不读字典、不保存，也不受规则开关影响。模拟译文临时代替 `{{TR}}`；修改输入会清除旧结果。

最多 64 条规则。编辑后点“确认规则”，再应用字典设置并保存字典；运行中的工作流下次同步时生效。规则不携带可执行脚本。

## 捕获黑名单

在“设置 → 文字处理 → 捕获黑名单”中配置排除规则。匹配的文字不会自动加入字典，也不会发送给 AI 翻译。默认排除纯数字、尺寸与数值单位、单字符、网址、邮箱、路径和快捷键；“任何包含数字的文本”默认关闭，`Selected:0` 这类属性计数可交给字典规则处理。

工作流文字列表直接应用捕获黑名单。字典中的词条仍可手动编辑和删除；清空字典会重置关联工作流的当前捕获记录；随后出现的文字（包括相同原文）正常收录。删除操作不会创建任何持续排除记录。

## 查看条目的处理状态

工作流的文字列表直接显示译文，编辑后自动保存到写入字典，不需要再点“添加到字典”。状态列同时显示处理结果与来源：

- **已翻译 / 未翻译**：完整条目的字典译文状态；“已在某字典”说明原文的归属。
- **规则翻译 / 规则待译**：显示规则编号；规则需要查词时，“译文来自某字典”说明捕获内容的译文来源。规则待译表示规则匹配了，但所需译文缺失。
- **规则置空**：规则输出为空文本。
- **已跳过**：说明具体文字过滤原因或手动忽略。
- **译文冲突**：同一原文存在需要选择的历史译文。

规则属于当前写入字典且引用一个固定词条时，可以直接编辑规则行：点进输入框编辑固定文字的译文，离开输入框后显示规则拼接的完整结果。例如在 `Total:18` 行填写“总计”，字典只保存 `Total → 总计`，所有计数行随之更新；清空也只删除这条固定词条。

可以按翻译状态、规则匹配、其他字典筛选。已观测且属于其他附加字典的条目也会显示；只读条目需要到所属字典修改。这里显示的是当前配置的解析结果，不代表目标软件已经刷新完成。


工作流列表默认将同一规则中的相同属性合并显示，例如 `Selected:0` 和 `Selected:20` 显示为一行，保留最近数值并累加次数。“任务操作 → 合并规则翻译”可切换显示方式；不删除字典词条或原始捕获记录。不同属性仍分别显示。
